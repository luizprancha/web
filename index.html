Commandos GIT

  • git init- criar repositório;
  • git add [file] :adiciona um arquivo no stage;
  • git status : exibe o estado do repositório;
  • git commit -m "msg" :cria um commit;
  • git log : exibe commits do repositório, da branch atual
  • git checkout referencia : muda o conteúdo da referencia para WK
