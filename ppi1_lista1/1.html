Diferença entre internet e Web

A internet é a infraestrutura física global (cabos, servidores, roteadores) que conecta computadores, funcionando como uma "estrada". A web (World Wide Web),
por outro lado, é um sistema de informações e páginas (sites) que roda sobre essa infraestrutura, agindo como o "veículo" ou conteúdo que você acessa via navegador.

Tim Berners Lee o criador da World Wide Web (WWW).

História da Internet e da Web

A Internet surgiu durante a década de 1960, como um projeto militar dos Estados Unidos chamado ARPANET. Seu objetivo era permitir a comunicação entre computadores mesmo em caso de ataques.

Com o passar do tempo, a internet evoluiu e passou a ser usada para fins acadêmicos e, posteriormente, comerciais. Um marco importante foi a criação da World Wide Web por Tim Berners-Lee em 1989.

Principais marcos

  • 1969 - Criação da ARPANET
  • 1983 - Padronização do protocolo TCP/IP
  • 1989 - Criação da Web
  • 1990 - Primeiro navegador

Ordem de evolução

  1. Internet militar
  2. Internet acadêmica
  3. Internet comercial
  4. Internet global

Termos importantes

Internet
Rede global de computadores interconectados.
Web
Sistema de documentos acessados via navegador.
HTML
Linguagem de marcação usada para criar páginas.
