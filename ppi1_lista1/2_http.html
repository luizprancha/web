O que é HTTP?

O HTTP (HyperText Transfer Protocol) é o protocolo usado para comunicação entre o navegador e os servidores na internet.

Quando você acessa um site, o navegador envia uma requisição e o servidor retorna uma resposta.

Como funciona

  • O navegador envia um pedido
  • O servidor processa
  • O servidor envia a resposta

Ilustração

Exemplo de requisição

GET /index.html HTTP/1.1
Host: www.exemplo.com

GET: pede uma página
/index.html: página solicitada
Host: endereço do site

Exemplo de resposta

HTTP/1.1 200 OK
Content-Type: text/html


Olá mundo

200 OK: deu certo
Content-Type: tipo do conteúdo
Body: conteúdo retornado

Códigos importantes

Código Significado
200 Sucesso
404 Página não encontrada
