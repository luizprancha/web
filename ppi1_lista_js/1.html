O que é JavaScript?

JavaScript foi criado em 1995 por Brendan Eich com o objetivo de tornar as páginas web mais interativas e dinâmicas. Inicialmente, ele era executado apenas no navegador, permitindo manipular elementos da página, validar formulários e responder a ações do usuário. Atualmente, JavaScript também pode ser executado no servidor através de tecnologias como Node.js.

No navegador, o JavaScript é executado dentro de um ambiente chamado sandbox, que limita o acesso ao sistema operacional do usuário por motivos de segurança. Já no servidor, o JavaScript possui acesso a arquivos, banco de dados e recursos do sistema.

Alguns objetos globais importantes do JavaScript no navegador são: document, utilizado para manipular elementos HTML; console, usado para registrar mensagens de depuração; e alert, utilizado para exibir mensagens na tela.
