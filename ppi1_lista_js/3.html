Tratamento de eventos em java Script

Tratamos evento em js usando addEventListener que vincula uma funcao a um evento especifico do DOM

exemplo

document.addEventListener('click', function(){ console.log('Clique Detectado!') })

Eventos comuns disponiveis nos navegadores

  • click - evento de clique
  • mouseover - evento de mouse sobre o elemento
  • mouseout - evento de mouse fora do elemento
  • mouseenter - evento do mouse entrando no elemento
  • keypress - evento de tecla pressionada
  • keydown - evento de tecla pressionada
  • keyup - evento de tecla solta
  • submit - evento de envio de formulario da tag form
  • DOMContentLoaded - eventoi disparado quando o doumento HTML é completamente carregado e parseado
  • change - evento disparado quando o valor de um elemento de formulario é alterado
